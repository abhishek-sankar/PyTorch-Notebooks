## How to choose

* **Prefer East‑Coast events**:  If travelling is a constraint, consider **Secure Software by Design 2025** in Arlington VA and **Carolina Code Conference** in Greenville SC. Both are on the East Coast and accept technical presentations—ideal for presenting research on Java code migration.
* **Java‑centric conferences**:  For deep discussions of JVM internals, attend the **Great Lakes Software Symposium** or the **JVM Language Summit**; these events offer direct connections to the Java community and often cover migration, refactoring and modernization of Java applications.
* **Security‑ and DevOps‑oriented events**:  If the migration project has a strong security component, **Secure Software by Design 2025**, **Black Hat USA**, **DEF CON**, **USENIX Security** and **DevOpsDays/KCDC** provide up‑to‑date practices and research in secure development and program analysis.
* **AI and agentic systems**:  To explore generative AI and agent‑driven approaches to code migration, **Ai4 2025** and **TechMentor** (sessions on generative AI) are useful.  They can help you understand state‑of‑the‑art AI agents that could automate software migration tasks.
